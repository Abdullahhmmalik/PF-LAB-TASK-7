# PF Lab Task 7

C programming lab solutions for PF Lab Task 7. This repository contains individual source files for the nine tasks, a formatted Word assignment document, and a combined text copy of the programs.

## Tasks included

1. Cinema Seat Booking
2. Student Marks Sheet
3. Weekly Temperature Report
4. Shop Sales Comparison
5. Hotel Room Occupancy Grid
6. Tic-Tac-Toe Winner Checker
7. University Result System
8. Warehouse Inventory
9. Library Book Catalog

## Files

- `Task_01_Cinema_Seat_Booking.c` through `Task_09_Library_Book_Catalog.c`: individual C programs, one per task.
- Word document: formatted assignment with code listings and sample console output screenshots.
- `PF_Lab_Tasks_07_All_Codes.txt`: all nine programs combined into one text file.
- `PF_Lab_Tasks_07_C_Source_Files.zip`: archive of the individual C source files and combined text file.

## Running a program

Open one `.c` file at a time in Dev-C++ or another C compiler, compile it, and run it. Each task is a separate program and has its own `main()` function.

## Note

These are introductory programming lab exercises. Review the task requirements and understand the logic before using or modifying the solutions.
